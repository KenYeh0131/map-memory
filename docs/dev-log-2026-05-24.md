## Map Memory 開發紀錄

### 本次完成項目

#### 1. 時間軸排序調整

已完成：

- 同一天回憶可長按拖曳排序
- 僅允許同日期內調整
- 不允許跨日期拖曳排序

排序邏輯：

- 先依日期分組
- 日期區塊不可互相混排
- 同日期內依使用者拖曳後的順序顯示

---

#### 2. 回憶填寫者註記

已完成：

新增回憶時，會記錄目前使用者暱稱。

時間軸顯示格式：

```

```

```
2026.05.24 Ken：回憶內容
2026.05.25 Abby：回憶內容
```

若舊資料沒有填寫者，則以原回憶內容顯示。

---

#### 3. 回憶編輯 / 刪除權限

已完成：

-   
只有該筆回憶的填寫者可以編輯  

-   
只有該筆回憶的填寫者可以刪除  

-   
其他使用者只能查看內容  


目的：

-   
避免多人共用地圖時誤改他人回憶  

-   
保留每個人的個人紀錄感  


---

#### 4. 時間軸功能精簡

已移除時間軸卡片上的：

-   
🚕 出發  

-   
＋回憶  


保留：

-   
📝 編輯  

-   
🗑️ 刪除  


調整後時間軸定位更偏向：

> 回憶日記 / 生活紀錄

而不是地點操作卡片。

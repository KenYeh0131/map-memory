## 6. 照片上傳速度改善

已完成：

### 地點照片

調整前：

- 使用 `FileReader.readAsDataURL()` 讀取圖片
- 容易造成手機畫面卡住
- 使用 `uploadBytes()`，無法顯示進度

調整後：

- 改用 `URL.createObjectURL()` 先建立本機預覽
- 避免先轉 base64
- 壓縮後再上傳
- 改用 `uploadBytesResumable()`
- 支援上傳進度回報

壓縮規格：

```text
格式：WebP
長邊最大：1600px
品質：0.75
```

### 回憶照片

已同步導入壓縮與進度顯示。

壓縮規格：

```text
格式：WebP
長邊最大：1600px
品質：0.75
```

保留限制：

```text
每次回憶最多 10 張照片
```

## 10. Build Error 修正

正式版 build 曾失敗：

錯誤：

```text
Type 'null' is not assignable to type 'BestTimingItem'
```

位置：

```text
app/page.tsx
normalizeBestTimings()
```

原因：

`.map()` 回傳：

```text
null
```

但 TypeScript 不允許：

```text
BestTimingItem[]
```

內含 null。

修正：

```text
.filter((item) => item !== null)
```

結果：

```text
npm run build
```

成功。

正式版可部署。

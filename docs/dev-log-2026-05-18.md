## 8. Build Error 修正

正式版 build 曾失敗：

錯誤：

```

```

```
Type 'null' is not assignable to type 'BestTimingItem'
```

位置：

```

```

```
app/page.tsx
normalizeBestTimings()
```

原因：

`.map()` 回傳：

```

```

```
null
```

但 TypeScript 不允許：

```

```

```
BestTimingItem[]
```

內含 null。

修正：

改：

```

```

```
.filter((item) => item !== null)
```

結果：

```

```

```
npm run build
```

成功。

正式版可部署。
